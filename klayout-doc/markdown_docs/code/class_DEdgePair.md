KLayout 0.30.5 (2025-12-11 6ad326e80) [master] KLayout Documentation (Qt 4): Main Index » Class Index » API reference - Class DEdgePair # API reference - Class DEdgePair Notation used in Ruby API documentation Module: db Description: An edge pair (a pair of two edges) - [Public constructors](#h2-13) - [Public methods](#h2-22) - [Public static methods and constants](#h2-91) - [Deprecated methods (protected, public, static, non-static and constructors)](#h2-96) - [Detailed description](#h2-107) Edge pairs are objects representing two edges or parts of edges. They play a role mainly in the context of DRC functions, where they specify a DRC violation by connecting two edges which violate the condition checked. Within the framework of polygon and edge collections which provide DRC functionality, edges pairs with integer coordinates ([EdgePair](class_EdgePair.md) type) are used in the form of edge pair collections ([EdgePairs](class_EdgePairs.md)). Edge pairs basically consist of two edges, called first and second. If created by a two-layer DRC function, the first edge will correspond to edges from the first layer and the second to edges from the second layer.
