Python specific notes: This method is the default initializer of the object. ### size Signature: [const] unsigned long size Description: Gets the number of single instances in the array If the instance represents a single instance, the count is 1. Otherwise it is na*nb. Starting with version 0.27, there may be iterated instances for which the size is larger than 1, but [is_regular_array?](#m_is_regular_array?) will return false. In this case, use [each_trans](#m_each_trans) or [each_cplx_trans](#m_each_cplx_trans) to retrieve the individual placements of the iterated instance.
