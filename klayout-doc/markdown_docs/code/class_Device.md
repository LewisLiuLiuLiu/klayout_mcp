Class hierarchy: Device » NetlistObject - [Public methods](#h2-13) - [Detailed description](#h2-92) Device object represent atomic devices such as resistors, diodes or transistors. The [Device](class_Device.md) class represents a particular device with specific parameters. The type of device is represented by a [DeviceClass](class_DeviceClass.md) object. Device objects live in [Circuit](class_Circuit.md) objects, the device class objects live in the [Netlist](class_Netlist.md) object. Devices connect to nets through terminals. Terminals are described by a terminal ID which is essentially the zero-based index of the terminal. Terminal definitions can be obtained from the device class using the DeviceClass#terminal_definitions method. Devices connect to nets through the Device#connect_terminal method. Device terminals can be disconnected using Device#disconnect_terminal. Device objects are created inside a circuit with Circuit#create_device.
