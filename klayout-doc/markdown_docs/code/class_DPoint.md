KLayout 0.30.5 (2025-12-11 6ad326e80) [master] KLayout Documentation (Qt 4): Main Index » Class Index » API reference - Class DPoint # API reference - Class DPoint Notation used in Ruby API documentation Module: db Description: A point class with double (floating-point) coordinates - [Public constructors](#h2-12) - [Public methods](#h2-23) - [Public static methods and constants](#h2-98) - [Deprecated methods (protected, public, static, non-static and constructors)](#h2-103) - [Detailed description](#h2-116) Points represent a coordinate in the two-dimensional coordinate space of layout. They are not geometrical objects by itself. But they are frequently used in the database API for various purposes. Other than the integer variant ([Point](class_Point.md)), points with floating-point coordinates can represent fractions of a database unit.
