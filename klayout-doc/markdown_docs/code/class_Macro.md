KLayout 0.30.5 (2025-12-11 6ad326e80) [master] KLayout Documentation (Qt 4): Main Index » Class Index » API reference - Class Macro # API reference - Class Macro Notation used in Ruby API documentation Module: lay Description: A macro class Sub-classes: Format, Interpreter - [Public constructors](#h2-16) - [Public methods](#h2-21) - [Public static methods and constants](#h2-124) - [Deprecated methods (protected, public, static, non-static and constructors)](#h2-151) - [Detailed description](#h2-162) This class is provided mainly to support generation of template macros in the DSL interpreter framework provided by [MacroInterpreter](class_MacroInterpreter.md). The implementation may be enhanced in future versions and provide access to macros stored inside KLayout's macro repository. But it can be used to execute macro code in a consistent way: path = "path-to-macro.lym" RBA::Macro::new(path).run() Using the Macro class with run for executing code will chose the right interpreter and is able to execute DRC and LVS scripts in the proper environment. This also provides an option to execute Ruby code from Python and vice versa. In this scenario you can pass values to the script using Interpreter#define_variable. The interpreter to choose for DRC and LVS scripts is Interpreter#ruby_interpreter.
