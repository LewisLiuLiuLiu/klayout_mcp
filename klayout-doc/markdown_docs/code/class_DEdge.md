An edge has a defined direction (from p1 to p2). Edges play a role in the database as parts of polygons and to describe a line through both points. The [Edge](class_Edge.md) object is also used inside the boolean processor ([EdgeProcessor](class_EdgeProcessor.md)). Although supported, edges are rarely used as individual database objects.
