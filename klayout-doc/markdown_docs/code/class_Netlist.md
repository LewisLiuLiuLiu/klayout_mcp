KLayout 0.30.5 (2025-12-11 6ad326e80) [master] KLayout Documentation (Qt 4): Main Index » Class Index » API reference - Class Netlist # API reference - Class Netlist Notation used in Ruby API documentation Module: db Description: The netlist top-level class - [Public constructors](#h2-13) - [Public methods](#h2-18) - [Deprecated methods (protected, public, static, non-static and constructors)](#h2-129) - [Detailed description](#h2-140) A netlist is a hierarchical structure of circuits. At least one circuit is the top-level circuit, other circuits may be referenced as subcircuits. Circuits are created with create_circuit and are represented by objects of the [Circuit](class_Circuit.md) class. Beside circuits, the netlist manages device classes. Device classes describe specific types of devices. Device classes are represented by objects of the DeviceClass class and are created using create_device_class.
