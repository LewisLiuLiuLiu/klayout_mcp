First, the plugins that grabbed the mouse with grab_mouse will receive this event with 'prio' set to true in the reverse order the plugins grabbed the mouse. The loop will terminate if one of the mouse event handlers returns true. If that is not the case or no plugin has grabbed the mouse, the active plugin receives the mouse event with 'prio' set to true.
