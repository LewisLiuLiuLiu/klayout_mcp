KLayout 0.30.5 (2025-12-11 6ad326e80) [master] KLayout Documentation (Qt 4): Main Index » Class Index » API reference - Class LogEntryData # API reference - Class LogEntryData Notation used in Ruby API documentation Module: db Description: A generic log entry - [Public constructors](#h2-13) - [Public methods](#h2-18) - [Public static methods and constants](#h2-65) - [Deprecated methods (protected, public, static, non-static and constructors)](#h2-76) - [Detailed description](#h2-87) This class is used for example by the device extractor (see NetlistDeviceExtractor) to keep errors or warnings that occurred during extraction of the devices.Other classes also make use of this object to store errors, warnings or information. The log entry object features a severity (warning, error, info), a message, an optional category name and description (good for filtering if needed) and an optional [DPolygon](class_DPolygon.md) object for indicating some location or error marker. The original class used to be "NetlistDeviceExtractorError" which had been introduced in version 0.26.
