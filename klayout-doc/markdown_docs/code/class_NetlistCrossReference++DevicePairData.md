This class is equivalent to the class NetlistCrossReference::DevicePairData - [Public methods](#h2-14) - [Detailed description](#h2-23) This object is used to describe the relationship of two devices in a netlist match.Upon successful match, the [first](#m_first) and [second](#m_second) members are the matching objects and [status](#m_status) is 'Match'. This object is also used to describe non-matches or match errors.
