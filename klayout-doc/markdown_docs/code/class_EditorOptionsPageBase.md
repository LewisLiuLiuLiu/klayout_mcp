You can use these methods in order to pass down events to the original implementation or access objects not created in script space. It features some useful methods such as 'view' and provides a slot to call for triggering a data transfer ('edited'). Note that even though the page class is derived from QWidget, you can call QWidget methods but not overload virtual methods from QWidget.
