KLayout 0.30.5 (2025-12-11 6ad326e80) [master] KLayout Documentation (Qt 4): Main Index » Class Index » API reference - Class PixelBuffer # API reference - Class PixelBuffer Notation used in Ruby API documentation Module: lay Description: A simplistic pixel buffer representing an image of ARGB32 or RGB32 values - [Public constructors](#h2-12) - [Public methods](#h2-17) - [Public static methods and constants](#h2-70) - [Deprecated methods (protected, public, static, non-static and constructors)](#h2-79) - [Detailed description](#h2-90) This object is mainly provided for offline rendering of layouts in Qt-less environments. It supports a rectangular pixel space with color values encoded in 32bit integers. It supports transparency through an optional alpha channel. The color format for a pixel is "0xAARRGGBB" where 'AA' is the alpha value which is ignored in non-transparent mode. This class supports basic operations such as initialization, single-pixel access and I/O to PNG.
